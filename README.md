# abalone-lite（推珠棋）

极简 Abalone 实现：六角棋盘上用 1~3 枚棋子推挤，把对方棋子推出棋盘。纯 Python 标准库，无第三方依赖。

## 玩法

- 棋盘：轴向坐标六角盘（半径 3，共 37 格），黑白双方各 8 子。
- 每回合选择 1~3 枚**同色、沿一条直线相连**的棋子，沿 6 个方向之一走一格：
  - **直线推进**：前方是空位直接走；前方是敌子时，只有己方数量**严格大于**敌方数量才能推挤（sumito，如 2 推 1、3 推 2；1 推 1、2 推 2 非法）。
  - **侧移**：所有落点必须为空。
  - 不能把自己的棋子走出棋盘。
- 被推出棋盘的敌子被吃掉。**先吃掉对方 4 子者获胜**（标准 Abalone 是 6 子，本版棋盘更小故取 4）。

## 用法

```bash
python3 -m abalone_lite --auto --games 5 --seed 42   # AI 对 AI 自动演示
python3 -m abalone_lite --auto --games 5 --verbose   # 打印每一步
python3 -m abalone_lite                              # 人机对战（黑先，需终端）
python3 -m abalone_lite --side w                     # 人类执白
```

人机对战时，程序会列出所有合法走法并编号，直接输入编号走棋，`q` 退出。

## 修复过的 bug

1. **`on_board` 参数 bug**：部分调用传入元组而函数签名是两个参数，`--auto` 首跑即 `TypeError`。已统一为接受元组。
2. **`apply` 颜色 bug（真 bug，测试抓到）**：推挤时被推移的敌子落点被错误涂成己方颜色。已改为按每枚棋子原色分别落子。

## 诚实局限

- **AI 很弱**：只是 1 步贪心启发式（吃子>子力>居中），不做深层搜索；贪心对贪心下黑方 5:0（先手优势被弱 AI 放大，random 对 random 下基本平衡）。熟悉规则的人类通常能赢。
- **简化规则**：37 格小棋盘、每方 8 子、吃 4 子获胜；标准 Abalone 是 61 格、每方 14 子、吃 6 子胜。不可当标准规则用。
- 400 半回合上限防无限对局，撞上限后按场上子多者判胜（真实对局极少见）。
- 文本棋盘，无图形界面/存档/悔棋；Python 3.10+，纯标准库。
